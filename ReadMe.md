### General Description 

When massive disclosure of documents, either voluntary disclosures or thefts, happen, then there is the problem of analyzing a massive ammount of data. The standard example are the wikileaks. 

For the Project, I plan to analyze the Epstein Files.

### Objectives of the Project

The aim is to count how many times people appear in the same discussion. And maybe to divide them by filo-democrats and filo-repubblicans, to see who has had more interaction with Epstein.
Moreover, I want to see if there is some italian cited there. 

We want to draw graphs whose nodes are the person and that have edges (and higher order simplexes). Moreover, I want to see the differences between the dataset 9 and the other ones

#### Censorship

- One of the problems we have to deal with is the censorship. Indeed, the distribution of the names we obtain is biased by the fact that only the names that have not been "blanked" -- and from the documents that have actually been published, are analyzed

- Moreover, it seems that, by some [Reddit posts](https://www.reddit.com/r/DataHoarder/comments/1qsfv3j/epstein_9_10_11_12_reddit_keeps_nuking_thread_we/), the dataset 9 contains particularly compromising information, as it has been leaked by error and has been forcefully removed from the internet
