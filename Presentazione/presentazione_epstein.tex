\begin{frame}{Il Dataset}
	Il dataset \footnote{ \href{https://github.com/maxandrews/Epstein-doc-explorer}{Link alla pagina github}} onsiste in \emph{triple semantiche}
\[
A \xrightarrow{B} C
\]

\begin{itemize}
    \item $A$ = Attore
    \item $B$ = Azione
    \item $C$ = Target
\end{itemize}
